# SmartLock
THis Smart Lock is made using Arduino Uno, Servo Motor, Red and Blue LED, OLED Display and a KeyPad.

 Connect the OLED’s GND to Arduino GND, VCC to 5V, SDA to A4, and SCL to A5. Connect the keypad rows to pins 9, 8, 7, and 6, and the keypad columns to pins 5, 4, 3, and 2. Connect the servo signal wire to pin 11. Connect the red LED to pin 10 and the green LED to pin 12.
